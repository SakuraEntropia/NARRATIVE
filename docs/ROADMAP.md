# Roadmap

1. Executable foundation: typed graph, atomic transitions, immutable persistence; exit when core regression tests pass.
2. Bounded construction and analysis: constrained refinement, sparse attention, polyphony; exit when offline fixtures and failure cases pass.
3. Controlled optimization: backward causal search, candidate branches, adversarial rules and Pareto selection; exit when original remains untouched and regression is rejected.
4. Memory and inspection: hard-budget context, dependency cache, telemetry, static HTML and experiments A–G; exit on reproducible CLI report.
5. External validation: independent model adapters, human reader panels, corpus-relative novelty, rubric reliability and blinded preference trials. Requires API funding and human data; artistic improvement remains an open hypothesis.
6. Scale and production hardening: indexed graph backend, incremental state checkpoints, schema migrations, larger randomized/property tests, richer temporal logic and authenticated collaboration. Requires profiling evidence and migration compatibility tests.

# Changelog

## 0.2.0 — 2026-10-20

Git-inspired local story version control: distinct immutable commits and content
blobs, persistent working copies, branches/tags and attached/detached HEAD,
revision selectors, structured diff and three-way merge, explicit conflict
resolution/abort, inverse reverts and inspectable reflog. Additive legacy database
migration preserves original rows. Optimistic checks reject stale writers,
including content-alias and dirty-copy replacements. Canon permissions and
forward simulation guard merge/revert results.

## 0.1.0 — 2026-10-19

Initial offline story engineering foundation: typed graph, persistence, state simulation, constrained refinement, analyses, controlled counterfactuals, evidence-bearing benchmark records, bounded memory, CLI and inspector.
